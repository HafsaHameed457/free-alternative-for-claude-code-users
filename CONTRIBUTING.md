# Contributing to opencode-for-claude-users

Thank you for your interest in contributing!

## How to Contribute

### 1. Fork the Repository

Click the "Fork" button on GitHub to create your own copy.

### 2. Clone Your Fork

```bash
git clone https://github.com/HafsaHameed457/free-alternative-for-claude-code-users
cd free-alternative-for-claude-code-users
```

### 3. Create a Branch

```bash
git checkout -b your-feature-name
```

### 4. Make Changes

- Follow the existing documentation style
- Use clear, concise language
- Include code examples where helpful
- Update the Table of Contents if adding new files

### 5. Commit Your Changes

```bash
git add .
git commit -m "Add: Description of your changes"
```

### 6. Push to GitHub

```bash
git push origin your-feature-name
```

### 7. Create a Pull Request

Go to the original repository and click "New Pull Request".

## Contribution Guidelines

### Documentation Standards

- Use Markdown formatting
- Keep lines under 100 characters when possible
- Include code blocks with language specifiers
- Add clear headings and subheadings

### Types of Contributions

- **New guides**: Add documentation for new OpenCode features
- **Corrections**: Fix typos, outdated info, or errors
- **Examples**: Add practical examples and use cases
- **Translations**: Help make docs accessible to more users

### Pull Request Requirements

- Clear title and description
- Explain what you changed and why
- Reference any related issues

## Questions?

- Open an issue for documentation questions
- Use GitHub Discussions for general questions
